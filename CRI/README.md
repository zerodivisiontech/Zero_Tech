

CRI | Capital Rotation Index (Baseline)
This was the original development environment for the CRI indicator.

The Build
The CRI was designed as a technical indicator to track and visualize capital flow across the crypto market. It identifies where liquidity is rotating in real-time to pinpoint market strength.

Status
The baseline logic from this repository is now being scaled into a dedicated infrastructure. To maintain the integrity of the original tool while building out the advanced version, the project has moved to its own gateway.
